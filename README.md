# NEXA · Asistente Académico Inteligente

Sitio web oficial del proyecto **NEXA**, un asistente académico móvil desarrollado con metodología **Scrum** para la materia *Fundamentos de Ingeniería de Software* del **TESH** (Semestre 5, Grupo 3501).

> Tu organización académica, simplificada.

## ✨ Características del sitio

- Hero con canvas de partículas animado y degradados mesh
- Efecto *typewriter* con frases del producto
- Cursor glow que sigue al usuario
- Modo claro / oscuro con un clic
- Barra de progreso de scroll y botón "volver arriba"
- Contadores animados y reveal on scroll
- Gráficas de barras animadas de esfuerzo por sprint
- Diagrama de arquitectura offline-first por capas
- Glosario Scrum (EP / HU / DoD / PO / SM)
- 25 preguntas de Sprint Review
- Tarjetas con efecto tilt 3D
- Marquee infinito de tecnologías
- 100% responsive y accesible

## 🚀 Ver la página

Abre `index.html` en cualquier navegador. No requiere servidor ni dependencias.

## 🌐 Publicar en GitHub Pages

1. Sube esta carpeta a un repositorio de GitHub.
2. Ve a **Settings → Pages**.
3. En *Source* selecciona **Deploy from a branch** → `main` → `/ (root)`.
4. Guarda. La página quedará en `https://<usuario>.github.io/<repo>/`.

## 🧱 Tecnología
